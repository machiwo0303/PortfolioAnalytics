# PortfolioAnalytics# JPX Portfolio Data Collector

JPX（日本株）のポートフォリオデータを収集し、分析用のデータセットを生成するためのツールです。  
購入日株価、現在株価、直近1年の配当金、損益、利回りなどを自動計算し、  
日次スナップショットとして CSV に出力します。

---

## 機能概要

- JPX 銘柄コードから yfinance を用いてデータ取得  
- 購入日の終値を自動取得  
- 現在株価の取得  
- 直近1年の配当金合計を算出  
- トータル配当金（配当 × 株数）  
- 配当利回り  
- 取得額・評価額・損益・損益率  
- ポートフォリオ全体のサマリー行を自動追加  
- 日付付き CSV ファイルとして保存（例：`portfolio_result_20260514.csv`）

---

## 入力ファイル形式（sample.csv）

以下の 3 列構成の CSV を読み込みます。

```
<銘柄コード>,<購入株数>,<購入日>
```

例：

```
1928,1,2026/5/11
9743,2,2026/5/7
6436,1,2026/5/7
2181,4,2026/5/7
4202,1,2026/5/7
3092,1,2026/5/6
```

---

## 出力される CSV

スクリプト実行時点の日付を付けて、以下の形式で保存されます。

```
portfolio_result_YYYYMMDD.csv
```

出力される列：

- 銘柄コード  
- 会社名  
- 業種  
- 購入株数  
- 購入日  
- 購入時株価  
- 現在日  
- 現在株価  
- 直近1年配当金  
- トータル配当金  
- 配当利回り  
- 取得額  
- 評価額  
- 損益  
- 損益率  
- 合計行（ポートフォリオ全体の集計）

## 使い方

### 1. 必要なライブラリをインストール

```
pip install pandas yfinance
```

### 2. sample.csv を用意

### 3. スクリプトを実行

```
python jpx_portfolio_collector.py
```

### 4. 出力ファイルを確認

```
portfolio_result_YYYYMMDD.csv
```

---

## スクリプト概要

- yfinance を利用して株価・配当データを取得  
- 購入日終値を取得して購入時株価を算出  
- 現在株価を取得  
- 直近1年の配当金を集計  
- 各銘柄の損益・利回りを計算  
- 最後にポートフォリオ全体のサマリー行を追加  
- 日付付き CSV として保存
